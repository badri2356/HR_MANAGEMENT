# NexusHR React UI

This project is a React/Vite implementation of the NexusHR UI/UX design supplied with the task.

## Included screens
- Sign in
- Admin Dashboard
- Employees
- Attendance & Leave
- Payroll
- Performance
- AI Insights
- Employee Mobile Home

## Run

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Notes
- The app is currently a front-end prototype with sample data from the supplied design.
- Sign-in/demo buttons enter the prototype dashboard.
- Sidebar navigation switches between the implemented screens.
- Backend/API integration can be added later.
- The mobile employee screen can be opened by changing `page` to `mobile` in `src/main.jsx`.
